# AVIX Game Balance Lab 2026

AVIX Game Design Academy 的遊戲數值設計教學工具。使用者可以調整參數，觀察數值如何改變遊戲節奏、難度與平衡結果。

## 模擬情境

- Boss Rush：攻擊窗口、玩家策略與操作能力
- Cooking Delivery：產能、等待時間與流程瓶頸
- Tower Defense：關卡路徑、資源配置與波次壓力
- Beat'em Up：群體戰鬥、波次壓力與清版節奏

## 使用方式

開啟 GitHub Pages 網站，從首頁選擇一種模擬情境即可開始。所有運算都在瀏覽器中完成，不會收集或上傳使用者資料。

## 本機開發

需要 Node.js 22 與 pnpm。

```bash
pnpm install
pnpm dev
```

## GitHub Pages

推送到 `main` 分支後，GitHub Actions 會自動建立並發布靜態網站。
